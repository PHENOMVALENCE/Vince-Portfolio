## Heritage

The project evolved from a ThemeWagon **Folio**-style HTML distribution. The root `README.md` retained from that heritage references MIT terms for the original template packaging. That notice is **template documentation**, not a substitute for a project-level license covering:

- Custom photography and personal brand assets
- Custom `executive.css` and `VM.*` JavaScript
- Written biography and case-study content

---

## Recommendation

For an open portfolio codebase (code only, excluding photos if desired):

1. Add an `LICENSE` file at the repository root (commonly **MIT** for code).
2. Explicitly state that **photographs, logo, and personal CV** remain all-rights-reserved to Vicent Manila unless otherwise granted.
3. If the site remains private/client-only, use a proprietary “All rights reserved” license instead.

**Do not invent ownership claims.** Have the client confirm the chosen license before publishing.
