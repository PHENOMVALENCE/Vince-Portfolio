## Overview

Photography is real Vicent Manila imagery. Site pages prefer **web-optimized** copies under `assets/images/Vince/web/`. Originals remain under `assets/images/Vince/`.

Central path map: `VM.images` in `assets/js/config.js`.

## Naming

- Prefer descriptive kebab or numeric names already in use (`event-11.jpg`, `alumni-summit.jpg`, `7.jpg`).
- Gallery entries in `gallery-data.js` include `src`, `thumb`, `alt`, `title`, `caption`, `category`, dimensions.
- Project galleries use `{ src, alt, position }`.

---

## Recommended dimensions

| Use | Guidance |
|-----|----------|
| Hero / portrait | Long edge ≥ 1200px; portrait orientation common |
| Project card / hero | ≥ 1200px wide when landscape; portraits OK with `imagePosition: top` |
| Gallery full | ≥ 1600px on long edge when possible |
| Thumbs | ~400–800px wide |
| Logo | High-res PNG with transparency (`vincelogo.png` is 1254×1254 source) |
| Favicons | 16, 32, 180, 192, 512 as present |

## Formats

Primary: **JPEG** for photos, **PNG** for logo/icons. WebP/AVIF not generated by the repo yet (roadmap item).

---

## Object position

Projects define `imagePosition`: `center` | `top` | `bottom` | `left` | `right` (mapped in `pages.js` `imgPos()`). Gallery items may set `position` similarly.

Always verify faces remain visible after cropping in 16:10 cards and wide heroes.

---

## Optimization practice

1. Export web JPEG quality ~70–85%.
2. Place site-facing files in `Vince/web/`, `Vince/web/gallery/`, or a named event folder under `Vince/web/events/`.
3. Update `config.js`, `data.js`, or `gallery-data.js` paths.
4. Provide thumbs for gallery grid when adding images.
5. Use `loading="lazy"` below the fold; heroes use `fetchpriority="high"` where set.
