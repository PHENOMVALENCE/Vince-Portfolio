Suggested filenames:

| File | Contents |
|------|----------|
| `desktop-home.png` | Homepage hero (desktop) |
| `desktop-projects.png` | Projects grid |
| `desktop-gallery.png` | Gallery masonry |
| `desktop-connect.png` | Connect section |
| `mobile-home.png` | Homepage stacked layout |
| `mobile-nav.png` | Open mobile menu |
